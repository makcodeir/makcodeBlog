راهنمای جامع و پیشرفته کنترل جریان با دستورات شرطی (if) در پایتون ​

در توسعه نرم‌افزار، توانایی اتخاذ تصمیم‌های پویا بر اساس داده‌های ورودی، هسته اصلی هر الگوریتمی است. در پایتون، کنترل جریان (Flow Control) عمدتاً توسط ساختار if مدیریت می‌شود.

در این راهنما، فراتر از سینتکس ساده خواهیم رفت و به بررسی الگوهای کدنویسی تمیز (Clean Code)، بهینه‌سازی شرط‌ها و ساختارهای پیشرفته می‌پردازیم.

۱. منطق پایه و ساختار کنترل جریان ​

در پایتون، بر خلاف بسیاری از زبان‌ها که از جفت‌آکولاد {} استفاده می‌کنند، بلاک‌های کد با Indentation (فاصله‌گذاری) مشخص می‌شوند. این ویژگی خوانایی کد را به شدت افزایش می‌دهد.

python
threshold = 85
score = 92

if score >= threshold:

	print(f"Success! Score {score} meets the criteria.")
else:
	print("Failure! Score is below the threshold.")

مفهوم Truthiness (حقیقت‌نمایی) در پایتون ​

یکی از ویژگی‌های متمایز پایتون، مفهوم Truthiness است. نیازی نیست همیشه صراحتاً تعداد اعضا یا طول یک متغیر را مقایسه کنید. اشیاء خالی در پایتون ذاتاً False ارزیابی می‌شوند.

python
user_sessions = []

if not user_sessions:

	print("No active sessions found. Redirecting to login.")

۲. ساختارهای شرطی چندگانه و درخت تصمیم‌گیری (elif / else) ​

زمانی که با بیش از دو حالت مواجه هستیم، از زنجیره if-elif-else استفاده می‌کنیم. در این ساختار، به محض برقرار شدن اولین شرط، بررسی مابقی شرط‌ها متوقف می‌شود.

python
user_role = "editor"

if user_role == "admin":
	access_level = "Full System Access"
elif user_role == "editor":
	access_level = "Content Management Only"
elif user_role == "viewer":
	access_level = "Read-Only Access"
else:
	access_level = "No Access"

print(f"Assigned Level: {access_level}")

۳.استفاده نادرست از if ​

بررسی تفاوت بین یک ساختار ضعیف و یک ساختار بهینه، نقش مهمی در درک عمیق تفکر الگوریتمی دارد.

الگوی مخرب: توی هم رفتگی شدید (Arrow Anti-Pattern) ​

کدی که به دلیل ifهای تو در تو (Nested)، خوانایی و نگهداری آن بسیار دشوار می‌شود:

python

is_active = True
is_valid = True
balance = 120 

if is_active:
    if is_valid:
        if balance >= 100:
            status = "Payment successful"
        else:
            status = "not balanced"
    else:
        status = "not valid"
else:
    status = "not active"

print(status)

۴. عملگرهای منطقی و ارزیابی میانبر (Short-Circuit Evaluation) ​

ترکیب شرط‌ها با and و or انجام می‌شود. در دستور A and B، اگر شرط A غلط باشد، پایتون هرگز بخش B را بررسی نمی‌کند، زیرا کل عبارت در هر صورت غلط خواهد بود. این ویژگی مانع از بروز خطاهای ناخواسته در زمان اجرا می‌شود:

python
user = None

if user is not None and user.is_authenticated:
print("User is logged in.")
else:
print("Access Denied.")

🛠️ چالش و تمرین عملی ​

برای سنجش میزان تسلط بر این ساختارها، مسئله زیر را پیاده‌سازی کنید:

صورت مسئله: فرض کنید یک سیستم محاسبات تخفیف طراحی می‌کنید. قوانین به این صورت است:

  • اگر مشتری عضو VIP باشد، 20% تخفیف می‌گیرد.
  • اگر مبلغ خرید بالای $200 باشد، بدون توجه به وضعیت عضویت، 10% تخفیف می‌گیرد (تخفیف‌ها با هم جمع نمی‌شوند و اولویت همیشه با تخفیف بالاتر است).
  • در غیر این صورت هیچ تخفیفی اعمال نمی‌شود.

هدف: این منطق را بدون استفاده از ifهای تو در تو و در بهینه‌ترین حالت ممکن بنویسید.
