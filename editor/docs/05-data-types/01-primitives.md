# primitives

Primitive values are the basic data values in JavaScript. Common primitives include strings, numbers, booleans, `null`, `undefined`, symbols, and bigints.

## Example
```js
const name = "Ava";
const age = 30;
const isActive = true;
const missingValue = null;
let notAssigned;

console.log(name, age, isActive, missingValue, notAssigned);
```
